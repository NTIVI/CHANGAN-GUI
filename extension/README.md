# Расширение CHANGAN.AM Portal Assistant

Официальное браузерное расширение для автомобильного портала **CHANGAN.AM**.

## Что делает расширение?
1. Добавляет плавающую круглую оранжевую кнопку на всех сайтах, которые вы открываете в браузере (YouTube, Яндекс.Карты, соцсети, поисковики и любые другие страницы).
2. При нажатии на кнопку вы мгновенно возвращаетесь обратно на сайт автомобильного портала: `https://changan-gui.vercel.app/`.
3. Кнопку можно свободно перетаскивать пальцем по экрану магнитолы в любое удобное место. Новая позиция автоматически запоминается.

## Инструкция по установке:
1. Скачайте архив `changan-extension.zip` и распакуйте его в удобную папку на устройстве.
2. Откройте в вашем браузере (Kiwi Browser, Яндекс.Браузер, Chrome, Edge) меню и выберите **Расширения** (или введите в адресную строку `chrome://extensions`).
3. Включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите распакованную папку.
5. Готово! Кнопка появится на всех открываемых страницах.
